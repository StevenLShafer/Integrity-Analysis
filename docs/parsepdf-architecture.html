ParsePDF · Architecture

How a trial PDF becomes a baseline table

ParsePDF extracts the baseline characteristics table of a randomized controlled trial and returns one row per variable per treatment arm, in the input layout of the Integrity-Analysis app. This map shows the pipeline, the one invariant that governs it, and — marked in red throughout — every step that can charge your Anthropic account.

The rule everything follows

Deterministic first, and it always wins

The invariant

The deterministic engine always runs first, and its numbers always win. The AI fallback only fills gaps, and never overwrites a value that was located on the page by coordinate. Every row records which engine produced it, because this data is used in research-fraud investigation and a reader must be able to tell the two apart.

Pipeline

Nine stages, one of which costs money

Stage detail

Why the two-column split comes first

Journals are typeset in two columns, and a table usually sits in one of them with body prose beside it. Clustering words into lines by y across the whole page glues each table row onto an unrelated sentence — this single defect made the parser fail on most real articles:

achieved with neostigmine (0.05 mg·kg –1 ) and gly-   Age (yr)  70 ± 6  71 ± 5

.ppPageBands() measures, for each 1-point column of x, the fraction of text lines writing into it, and calls a long low-coverage run a gutter. Low rather than zero matters: the running head, the title and full-width footnotes all cross the gutter.

ROUND_MEAN is read from the printed glyphs, never inferred from the value: 63 has 0 decimals and 63.0 has 1. That distinction is data — it tells the Monte Carlo analysis how much of a discrepancy rounding alone can explain.

Submitted manuscripts (2026-08-20)

The deployed app screens submissions, not published articles. Screening 654 RCT submissions from the A&A manuscript corpus found five manuscript-specific defeats, each repaired and pinned as a synthetic fixture in test-manuscript-layouts.R: margin line-number rails (.ppStripLineNumberRail()); legend sentences between the caption and the table (tolerated until the first data line); captions physically separated from their table (a data-less caption queues a full-width look-ahead candidate for the next page); tables running over the page break (the winning full-width parse extends while the score improves); and the gutter detector splitting a wide Word table into a labels band and a values band (the score now rewards demographic row labels and penalises nameless rows, so the full-width reading wins). Two notation repairs came with them: mean±SD written without spaces no longer counts as evidence for the dash-for-± rewrite, and a block whose legend announces mean - SD has contiguous 40.79-11.97 pairs re-read as mean ± SD, only on lines with two or more such pairs. Measured on a seeded 60-submission sample: template lines 475 → 1,116, mean/SD variables 95 → 254, arms with a known N 17 → 80; the 150-article published-corpus sample improved from 102 to 117 articles yielding a table.

One file spends money

R/aiFallback.R is the only file that touches the network. Everything else — reading the PDF, finding the table, parsing it, writing the spreadsheet — is free, offline and reproducible. Charges go to the Anthropic Console account whose key is in ANTHROPIC_API_KEY.

Guards already in place

With no key set, the hybrid returns the deterministic result and its flags rather than erroring. parseBaselineTableFiles() defaults to ai = "never" and announces how many files may be sent before any call is made. maxTokens caps each reply; maxChars caps the prose request.

Two habits worth keeping

Page selection is deterministic and free. Before spending on a batch, check what .ppBestCaptionPage() chooses — sending the model the wrong page produces a confident "there is no table here", and you pay for it anyway.

Auto-reload means a runaway loop bills silently. Scope any corpus run with a small head() first.

Prices are claude-opus-5 list at the time of writing — $5 per million input tokens, $25 per million output, thinking billed as output. Check current pricing before relying on these figures.
